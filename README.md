## 👨‍💻 About Me

I'm **Omid Khan**, a Data Engineer and Software Developer with a background in machine learning, cloud computing, automation, and data analytics.

I hold a **Master of Information and Data Science from UC Berkeley** and a **B.S. in Computer Science from California State University, East Bay**.

My work focuses on designing reliable data pipelines, building intelligent applications, automating workflows, and transforming complex datasets into actionable insights.

- 🔭 **Currently building:** OnlyPhysys, a physical media cataloging and collection analytics platform.
- 🧠 **Specialties:** Data Engineering, AI/ML, ETL/ELT, Cloud Infrastructure, and Automation.
- ☁️ **Cloud experience:** Microsoft Azure and Google Cloud Platform.
- ⚙️ **Engineering interests:** Distributed systems, data orchestration, full-stack development, and robotics.
- 🎯 **Focus:** Building practical, scalable software that solves real-world problems.
